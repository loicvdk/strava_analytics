This file will be used to create the python visualisation of the strava data for now only focusing on run data. 

The frontend will have 3 sections 
1. high level statisctics:
    - numbers of kms this week
    - number of kms YTD
    - average pace this week (in min/km)
2. graphs 
    - line chart of weekly kms (with ability to switch between last 90 days, last 6 months, YTD and all time)
    - barchart average pace per week 
    - time spent per week
3. activities list 
    - list of all activities with columns mentioning the name, distance, time and average speed
